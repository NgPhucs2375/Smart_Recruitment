# CV-theme matching

```powershell
dotnet run --project "tests/CvThemeMatching.Checks/CvThemeMatching.Checks.csproj" -p:UseSharedCompilation=false -m:1
```

Covers structured ranking, language/level aliases, strict constraints, missing
context, inactive/unrenderable themes, actual renderer versions/layouts, own-CV
scope, draft precedence, no persistence, function schema and routing regressions.
